Element diggs:ComponentLithType / diggs:classificationCode
Namespace http://diggsml.org/schemas/3
Annotations
 
The lithology as a controlled term (a classification code or
controlled name) rather than a descriptive one. For USCS
(ASTM D2487, D2488) it is the group name with its modifiers,
for example "Silty sand" or "Gravelly silt with sand"; where
only the group symbol is reported, use the unmodified group
name for the symbol. For AASHTO it is the group or subgroup
(for example "A-3", "A-2-6"); for USDA, Shepard or Folk
textural classifications, the full-text class (for example
"sandy loam", "sand-silt-clay", "muddy Sand"); for the
British Soil Classification System, the recommended name
(for example "CLAY of very high plasticity") or the group
symbol if no standard name is given; for rock, the rock
name, for example from the American Geosciences Institute
glossary ("Dolostone", "Basalt"). Either classificationCode
or lithDescription must be present. The codeSpace attribute
is the URL of a GML dictionary that defines the terms of the
classification system, and the value equals the gml:name of
the matching diggs:Definition, for example the entry SWg of
astmD2488.xml with the value "Well-graded sand with gravel".
A system without an online dictionary may be used with a
codeSpace that is a URL to an online resource describing it,
but interoperability is limited and a dictionary should be
developed. Use the DIGGS dictionary for the classification
system applied: USCSSoilComponents.xml, aashtoM145.xml,
astm2488Brdr.xml, astmD2487.xml, astmD2488.xml,
astmD5715.xml or usda.xml.

Element diggs:ComponentLithType / diggs:lithDescription
Namespace http://diggsml.org/schemas/3
Annotations
 
Descriptive information about the lithology, including
color, facies, grain size distribution, constituents and
field properties, even where these are also encoded (for
example: well-graded sand (SW), fine-grained, dark grey,
massive, dry, hard). Give it with classificationCode; it is
preferred that both are present.

Element diggs:ComponentLithType / diggs:classificationSymbol
Namespace http://diggsml.org/schemas/3
Annotations
 
The group symbol (USCS) or the group or appropriate subgroup
classification (AASHTO and BSCS) of a soil classification. Symbols
of non-standard or proprietary classifications may also be reported.
The codeSpace attribute is mandatory: preferably a link to the DIGGS
dictionary, or USCS, AASHTO or BSCS for those systems, or an
authority code for a non-standard system. Use the DIGGS dictionary
for the classification system applied: grp-aashtoM145.xml,
grp-astmD2487.xml, grp-astmD2488.xml or grp-astmD2488Brdr.xml.

Element diggs:ComponentLithType / diggs:groupIndexAASHTO
Namespace http://diggsml.org/schemas/3
Annotations
 
For soils classified by the AASHTO system, the group index GI =
(F-35)[0.2+0.005(LL-40)]+(F-15)(PI-10), where F is the percentage
passing the 75 micrometer sieve as a whole number, LL is the liquid
limit and PI is the plasticity index.

Element diggs:ComponentLithType / diggs:color
Namespace http://diggsml.org/schemas/3
Annotations
 
A color whose boundaries match those of the lithology observation.
Where significant color changes do not match those boundaries,
define a diggs:ColorSystem rather than separate lithology
observations; minor color changes within the observation can be
given as a description in a diggs:PlacedObservation. Repeat for each
color.

Element diggs:ComponentLithType / diggs:constituent
Namespace http://diggsml.org/schemas/3
Annotations
 
A material or structure associated with the lithology that is not
significant enough to record in a diggs:ConstituentSystem, or whose
location within the observation need not be preserved. Constituents
are sedimentary or physical structures; lithologic, mineralogic or
organic accessories (calcite, gas odor); bioturbation features;
diagenetic structures; physical structures produced by sampling;
fossils; trace fossils; and fractures. Repeat for each constituent.
