Element diggs:DesignRITreatedAreaType / diggs:designLoad
Namespace http://diggsml.org/schemas/3
Annotations
 
The applied loads this system design must resist, such as embankment
self-weight, traffic, a structure or slab load or a surcharge. They
are held here rather than on diggs:DesignRILTPType because not every
load a site must resist is transmitted through a load transfer
platform; a footing or tank load may bear on improved ground
directly. Each diggs:DesignLoad's own appliesToZoneRef states which
part of the site it governs where loading differs by zone.

Annotations
 
Delta-s: the predicted differential or surface settlement. It is
meaningless without its basis (between adjacent column heads, across
a unit cell, over a 100 ft span, or as an angular distortion), which
differentialSettlementBasis and differentialSettlementBaseLength

the serviceability criterion it is checked against are comparable
field by field.

Element diggs:DesignRITreatedAreaType / diggs:methodApplicabilityRatio
Namespace http://diggsml.org/schemas/3
Annotations
 
A dimensionless geometry or stiffness ratio that gates whether the
unit-cell idealization of an arching method is valid for this zone's
layout: h/(s-d), d/s, sx/sy and the EBGEO stiffness ratio ks,T/ks,
and whatever a later method's applicability check needs. Each
repetition is a diggs:AuthorizedParameter or
diggs:ProvenancedParameter bound to a definition in
ri_design_properties.xml; the property type is
diggs:AuthorizedParameterPropertyType, not
diggs:ParameterPropertyType, so the schema itself enforces a
dictionary-bound name with a mandatory codeSpace. It is a
whole-system judgment, like
diggs:DesignRITreatedAreaType/verification: whether the assumption
of a method holds for the layout of the zone is evaluated at zone or
system level, even though its ingredients come from component
designs (spacing and diameter on diggs:DesignRIColumnType,
embankmentHeight on diggs:DesignRILTPType), and h/(s-d) needs both.
It is a named container rather than diggs:otherProperty so that a
dictionary Occurrence can scope an entry to exactly this element
(ancestor::diggs:methodApplicabilityRatio). Give the ratio itself
here, such as ks,T/ks; the pass/fail requirement it must clear is a
verdict, not a value. Repeat for each ratio.

Element diggs:DesignRITreatedAreaType / diggs:seismicSiteClass
Namespace http://diggsml.org/schemas/3
Annotations
 
The seismic site classification (IBC/ASCE 7 Site Class A-F) that the
design predicts for the treated ground after improvement. It is a
predicted output, of the same kind as predictedSettlement, and
belongs on the design. A required minimum site class is a constraint
the work is judged against and belongs on a
diggs:PerformanceCriterion, as for a minimum shear-wave velocity: do
not use this element to state a requirement, since a missed
prediction is a finding whereas a missed requirement is a
non-conformance. Its as-built counterpart is
diggs:RITreatedAreaType/seismicSiteClass, which carries the class
achieved; the pair has the same vocabulary and subject, one
predicted and one verified. Values come from the enumerated list, or
"Other: xx", where xx is a user-defined term whose meaning differs
from every listed value (not a synonym of one).
