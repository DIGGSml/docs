Element diggs:ReinforcementType / diggs:reinforcementType
Namespace http://diggsml.org/schemas/3
Annotations
 
The configuration of the reinforcement: rebar cage, single central
bar, structural steel section, and so on. It is distinct from
steelGrade and barSize, which describe the material and the
individual bars rather than the arrangement. Values come from the
enumerated list, or "Other: xx", where xx is a user-defined term
whose meaning differs from every listed value (not a synonym of
one).

Element diggs:ReinforcementType / diggs:cover
Namespace http://diggsml.org/schemas/3
Annotations
 
The concrete cover over this reinforcement: the minimum distance
from the bar or cage surface to the outer concrete surface of the
column, which governs protection of the reinforcement against
chloride and sulfate ingress and carbonation. Required cover is
typically set by the exposure classification that a
diggs:RIProgramBasis states (exposureClassification) with the
governing durability standard, but it is given here as a plain
length rather than derived, since the design record should carry
what was actually specified.

Element diggs:ReinforcementType / diggs:corrosionProtection
Namespace http://diggsml.org/schemas/3
Annotations
 
A corrosion protection measure specified for this reinforcement
beyond cover alone, for example galvanizing, an epoxy coating or
cathodic protection. Protection is usually specified as a
combination of measures, so repeat for each measure in force.
Increased cover is itself a protective measure: give its code here
to say the measure was adopted, and its magnitude in cover. Use
remark for anything a code cannot capture. Use the DIGGS dictionary
corrosionProtection.xml for the list of values.
