Element diggs:DesignRITreatedArea
Namespace http://diggsml.org/schemas/3
Annotations
 
The site-wide design for a rigid inclusion foundation system: the design properties
that hold across the whole system, from which zone- and element-level designs
depart. It is a thin carrier and does not contain the column, LTP or grout designs,
which are declared as siblings under the program. A diggs:DesignRIColumn or
diggs:DesignRILTP for a particular zone cites this object through basedOnRef, and
property resolution runs most-specific-first: a zone design that states no value for
a property inherits the value stated here.
