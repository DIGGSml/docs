Element diggs:AcceptanceCheckType / diggs:determination
Namespace http://diggsml.org/schemas/3
Annotations
 
How the verdict was reached: from a measured value, a derived value
or a declaration. Values come from the enumerated list.
Diagram
Type diggs:DeterminationEnumType
Properties
content simple
Facets
enumeration measured 
The compared value was measured or recorded directly - on the
subject itself or in cited evidence.
enumeration derived 
The compared value was computed from recorded values - for
example an as-built position against its design position, or the
embedment of a column toe below a modelled unit surface.
enumeration declared 
No value was compared; conformance was asserted by the party
identified on the evaluation - for example by inspection.
