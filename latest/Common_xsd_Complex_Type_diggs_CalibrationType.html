Element diggs:CalibrationType / diggs:calibrationResults
Namespace http://diggsml.org/schemas/3
Annotations
 
A table of calibration points: one row per point, with
columns such as the reference value applied, the value the item
indicated, the deviation between them and the expanded uncertainty
at that point. The columns, their units and their order are
declared by the table's parameters. An item calibrated over more
than one range or quantity carries one table for each.
