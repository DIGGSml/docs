Element diggs:ProvenancedParameterType / diggs:subjectRef
Namespace http://diggsml.org/schemas/3
Annotations
 
A reference to the feature or object that the parameter value
describes, for example a geotechnical unit, a material or a sampling
feature. Optional because the subject is sometimes evident from the
object or property that holds the parameter; state it explicitly
wherever that context is not enough to identify the subject
unambiguously.
