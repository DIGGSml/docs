Element diggs:PropertyType / diggs:propertyName
Namespace http://diggsml.org/schemas/3
Annotations
 
A code or name for the property as used by the data provider. It can
come from a controlled list of terms or be an uncontrolled text
string, and is commonly used to label a column of a log sheet or
give the property a local meaning. The value must be unique among
the properties in the dataValues block transmitted as part of this
measurement. No DIGGS-authored dictionary currently exists for this
element.

Element diggs:PropertyType / diggs:srsDimension
Namespace http://diggsml.org/schemas/3
Annotations
 
For properties that represent a position (for example depth down a
borehole, or a geographic position, both in a time-indexed record),
the dimensionality of the spatial reference system. Where
srsDimension is greater than 1, the coordinates in the dataValues
block cannot be space-separated, because a parser would read the
space as the end of a data record; separate them with |, so that
coordinates 10 4 12 are written 10|4|12.
