Element diggs:WorkingPlatformType / diggs:wpExtent
Namespace http://diggsml.org/schemas/3
Annotations
 
The surface extent of the working platform. If omitted, there can be
only one diggs:WorkingPlatform and its extent is that of
diggs:RITreatedArea. It is typically in a 2D CRS, because the
elevation of the platform is given by the mandatory wpElevation,
which overrides any elevation in wpExtent. It may be stated inline
or by reference: where the extent is the same polygon as something
already declared, for example the featureExtent of a
diggs:LoadTransferPlatform with which one of several platforms
coincides, cite it by xlink:href rather than restating it.

Element diggs:WorkingPlatformType / diggs:totalArea
Namespace http://diggsml.org/schemas/3
Annotations
 
The total area of the working platform. This is a convenience property designed so that consumers do not need to compute total area from RITreatedArea/featureExtent or, if present, wpExtent. If there is disagreement between totalArea and the area computed from the geometry, the geometry prevails.

Element diggs:WorkingPlatformType / diggs:wpElevation
Namespace http://diggsml.org/schemas/3
Annotations
 
The elevation of the working platform. As the platform is required to be horizontal, this value is a
position, not an averaged level, that should be expressed as a one-dimensional position in a vertical CRS. This property is mandatory - its value overrides any elevation that may be expressed in the working platform's wpExtent or in the RITreatedArea's featureExtent.

Element diggs:WorkingPlatformType / diggs:wpMaterial
Namespace http://diggsml.org/schemas/3
Annotations
 
The material of the fill placed beneath the working platform,
typically a well-graded compacted granular fill. It describes the
fill, not the platform, because the working platform is a surface
and has no material of its own; fill exists only where needed to
reach the bearing capacity the installation equipment requires, and
where the natural ground already provides that no fill is placed and
this property is absent. It pairs with avgFillThickness, and the two
are absent together. It is not the same as
diggs:LTPLiftType/materialType, though both are
diggs:LithologyPropertyType: a working platform is temporary
construction access prepared before the columns and characterized by
the rig load it must carry, whereas a load transfer platform is
permanent structure built after the columns over their heads and
characterized by how it distributes load onto them. Where an LTP
happens to be founded on the former working platform, that is a
construction-sequence fact about two distinct features.

Element diggs:WorkingPlatformType / diggs:wpBearingCapacity
Namespace http://diggsml.org/schemas/3
Annotations
 
The bearing capacity the working platform was verified to provide
before rigid inclusion installation began, sufficient to carry the
maximum ground pressure exerted by the drill rigs, grout pumps and
support equipment used to install the columns. It is a threshold
verified once, not a design value tracked against an as-built
outcome: adequacy is a go/no-go check before the work starts, and if
the existing ground cannot carry the equipment the site is modified,
typically with a granular platform layer, often
geosynthetic-reinforced, until it can.

Element diggs:WorkingPlatformType / diggs:avgFillThickness
Namespace http://diggsml.org/schemas/3
Annotations
 
The average thickness of fill placed over the existing ground level
below the working platform surface; assumed zero if absent. The
average natural ground surface elevation below the working platform
is wpElevation minus avgFillThickness. It is a length, not a
position, and the one property of this object that is not an
elevation: a thickness has magnitude but no location, must be able
to take the value zero, and is subtracted from an elevation to yield
one. Contrast wpElevation and avgWTLevel, which are
diggs:PointLocationPropertyType because each names a definite place
in a vertical CRS.
