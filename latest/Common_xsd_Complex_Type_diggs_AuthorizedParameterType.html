Element diggs:AuthorizedParameterType / diggs:parameterName
Namespace http://diggsml.org/schemas/3
Annotations
 
A code identifying what the value represents. The codeSpace
attribute is mandatory and must give the URI of the definition in a
properties dictionary (the dictionary's URI with the entry id, for
example the liquid_limit entry of properties.xml), so that an
application can resolve and validate the name. Where no such
definition exists, use diggs:Parameter instead. Use the DIGGS
dictionary that serves the host element: properties.xml,
ri_design_properties.xml, design_basis_properties.xml,
design_factor_properties.xml, designProperty.xml,
evidenceCondition.xml or gp_properties.xml.

Element diggs:AuthorizedParameterType / diggs:typeData
Namespace http://diggsml.org/schemas/3
Annotations
 
The data type of the parameter value, for example double, long or
string. Required: declaring the type is the point of this object, so
that a consumer need not infer it from the lexical form of the value
or resolve the dictionary definition to obtain it. Unlike
diggs:PropertyDataTypeEnumType, it does not permit the empty string,
because there is no unknown-type case here. Values come from the
enumerated list.
