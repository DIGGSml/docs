Element diggs:InstallationSequenceType / diggs:sequenceRule
Namespace http://diggsml.org/schemas/3
Annotations
 
The traversal that generates the installation order over the
grid: Linear or Boustrophedonic, with axisOrder stating which
axis varies fastest and the direction along each. The rule names
are restricted to these two; state any other order with
gridIndexStep.

Attributes
QName Type Use Annotation
axisOrder gml:AxisDirectionList optional 
Which axis of the grid's index space varies fastest, and the direction
along each: a whitespace-separated list of signed, 1-based axis numbers,
for example "+1 +2" or "-2 +1". The numbers index the grid's own axes,
in the order its axisLabels and offsetVectors declare them, not the axes
of the CRS named by srsName. The sign is the direction: + runs from
gml:low to gml:high, - from high to low. Position in the list is
precedence: the first axis named varies fastest, the last slowest. Each
axis of the grid appears exactly once. Where omitted, the axes are taken
in their declared order, all ascending ("+1 +2" on a two-dimensional
grid).

Element diggs:InstallationSequenceType / diggs:gridIndexStep
Namespace http://diggsml.org/schemas/3
Annotations
 
One explicitly ordered node, the alternative to a generated
traversal. The content is the grid index of the node, a
diggs:GridIndexType like diggs:realizesGridIndex and
plannedGridIndex, and the sequenceNumber attribute states its
position in the order. The entries account for every node of the
design's plannedPositions grid, each node once, with the sequence
numbers running 1 to n; the schema does not enforce either. Use it
for an order no rule generates, such as (1,1) then (10,2) then
(1,2).

QName Type Default Use Annotation
dimension positiveInteger 2 optional 
The number of values in the index, equal to the dimension of the grid it
indexes. It is two where omitted; state 3 for an index into a
three-dimensional grid.
sequenceNumber positiveInteger required 
The position of this node in the installation order, counting from 1. It
is stated on the step, not left to document order, so it survives
reserialization and can be compared with the as-built
diggs:RIColumnType/installationSequenceNumber. The numbers of one
sequence run 1 to n, counted within this design; a
diggs:DesignProductionSequence places the design among the program's
other work.
