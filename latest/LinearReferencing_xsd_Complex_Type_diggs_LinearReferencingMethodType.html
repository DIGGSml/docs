Element diggs:LinearReferencingMethodType / diggs:positiveDirection
Namespace http://diggsml.org/schemas/3
Annotations
 
The direction in which measured values increase along the linear
element. Measurement always proceeds from the first to the last
coordinate; the values other than increasing are labels that say
what that direction means, for example downward for a borehole.
Values come from the enumerated list.
Diagram
Type diggs:PositiveDirectionEnumType
Properties
content simple
minOccurs 0
default increasing
Facets
enumeration increasing 
Positive follows the coordinate order, from the first to the last
coordinate. This is the standard convention.
enumeration downward 
Label for positive being downward (deeper), common for boreholes where the
first coordinate is the collar and the last is the bottom of the hole.
enumeration upward 
Label for positive being upward (shallower), for example for core logged
from bottom to top, or for elevation-based referencing.
enumeration forward 
Label for horizontal features: positive is the forward direction of the
survey or alignment, common for transects, pipelines and tracklines.

Element diggs:LinearReferencingMethodType / diggs:offsetParameters
Namespace http://diggsml.org/schemas/3
Annotations
 
The parameters of the lateral offset, for methods that support one,
for example for transects, tracklines with swath data, pipelines
with offset monitoring points, or trial pits with offset sampling
locations. When present, the method is two-dimensional: a linear
spatial reference system using it has srsDimension 2 and a position
is encoded in gml:pos as the distance along, in units, then the
offset, in offsetParameters/offsetUnits. When absent, the method is
one-dimensional: srsDimension is 1 and a position is the distance
alone.
