Element diggs:GeoUnitDesignQuantityType / diggs:downdragTreatment
Namespace http://diggsml.org/schemas/3
Annotations
 
How downdrag was accounted for in the axial analysis of this unit:
the neutral-plane method, downdrag folded into a limit-strength
check rather than located at a computed plane, engineering
experience, or not considered. It governs negativeSkinFrictionLimit,
neutralPlaneDepth and maxAxialForceAtNeutralPlane in the same way
limitState does, and is stated once per instance for the same
reason: two designs reporting the same neutral-plane depth arrived
at by different treatments are not comparable. It is declared on
this per-unit type, and not only on diggs:RIProgramBasisType,
because the values it qualifies live here and a
conditionalElementXpath predicate can see only local containment,
not the target of a basisRef. Use the DIGGS dictionary
downdragTreatment.xml for the list of values.
