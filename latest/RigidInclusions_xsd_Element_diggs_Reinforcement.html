Namespace http://diggsml.org/schemas/3
Annotations
 
Steel reinforcement occupying one interval of a rigid inclusion column: a cage over
the top few metres at an edge column, or full length where bending governs.
Reinforcement in rigid inclusions is the exception rather than the rule; where
present it is zoned, so the object carries the interval it occupies rather than a
bare length. One object serves both the design and the as-built side:
diggs:DesignRIColumnType carries it as the required reinforcement and
diggs:RIColumnType as the installed reinforcement, and either host repeats it for a
column with more than one reinforced zone. intervalLocation is modelled on
diggs:TaperType/intervalLocation, the depth-interval-scoped property on a linear
installation.
