Element diggs:SampleType / diggs:relativeReferencingSystem
Namespace http://diggsml.org/schemas/3
Annotations
 
A relative spatial reference system for a core or block sample,
locating positions within the sample instead of relative to the
sampling feature's origin. The linearElement of
diggs:LinearSpatialReferenceSystem then references the sample's
location rather than the sampling feature's. Use
diggs:LinearSpatialReferenceSystem or diggs:LocalCartesianCRS;
diggs:VectorLinearSpatialReferenceSystem is deprecated.

Element diggs:SampleType / diggs:type
Namespace http://diggsml.org/schemas/3
Annotations
 
The type of sample. Terms can be general ("bulk", "core") or
organization specific, and may incorporate the sample class
("water"), the sampler ("piston sample"), the method ("push
sample"), the condition ("undisturbed thin wall tube sample"), the
purpose ("soil sample for environmental testing") or an associated
test ("SPT sample"). Each serves as shorthand for information also
held by other sample or sampling activity properties. Use the DIGGS
dictionary sampleType.xml for the list of values.
