Element diggs:LTPLiftType / diggs:materialType
Namespace http://diggsml.org/schemas/3
Annotations
 
The material used to construct this lift. Not to be confused with
diggs:WorkingPlatformType/wpMaterial: a working platform is
temporary construction access built before the columns, whereas a
lift is permanent structure placed after them, over the trimmed
heads. The material is held on the lift rather than the platform so
that a platform built of more than one material can be described.

Element diggs:LTPLiftType / diggs:heightAboveWorkingPlatform
Namespace http://diggsml.org/schemas/3
Annotations
 
The distance between the working platform surface and the top of
this lift, so the elevation of the lift top is wpElevation plus this
value. It is cumulative, not per lift: it is measured from the
working platform every time, so in a platform of contiguous lifts it
increases with each lift while liftThickness does not. The topmost
lift's value is the thickness of the whole platform and equals
impliedLTPThickness. It has the same name, type and datum as
diggs:GeosyntheticType/heightAboveWorkingPlatform, so both objects
contained by a platform are measured the same way. It is mandatory
here, unlike on the geosynthetic, because a lift has no extent
geometry to carry its position.

Element diggs:LTPLiftType / diggs:liftThickness
Namespace http://diggsml.org/schemas/3
Annotations
 
The vertical distance between the top and base of this lift alone,
not of the platform. It is strictly greater than zero, since a lift
of no thickness was not placed. For the platform as a whole see
diggs:LoadTransferPlatformType/impliedLTPThickness.
