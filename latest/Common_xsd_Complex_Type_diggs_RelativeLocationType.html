Element diggs:RelativeLocationType / diggs:frameConvention
Namespace http://diggsml.org/schemas/3
Annotations
 
What the axes of relativePosition2D and relativePosition3D mean; it
is required for them to be meaningful, since there is no CRS to
define them. Not meaningful for depth and distance, which are
self-describing one-dimensional measures with only one axis to name.
The codeSpace is required. Use the DIGGS dictionary
frameConvention.xml for the list of values. The dictionary is
provisional: it was built from practice (station, offset and
elevation project baselines; trench and test-pit face logging grids)
rather than from a single citable naming standard.
