Complex Type diggs:AbstractProgramDesignType
Namespace http://diggsml.org/schemas/3
Annotations
 
Abstract base type for program designs, which define the planned characteristics and
requirements of a program of work: target parameters, acceptance criteria, testing
frequencies and quality control measures. A design can be compared with the actual
implementation to track compliance and identify deviations.
