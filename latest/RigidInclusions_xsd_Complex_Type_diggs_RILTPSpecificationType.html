Element diggs:RILTPSpecificationType / diggs:aggregateGradationCurveCoarseLimit
Namespace http://diggsml.org/schemas/3
Annotations
 
The coarse bound of the permitted gradation envelope for the
platform fill: the curve the material may not be coarser than. With
aggregateGradationCurveFineLimit it defines the band a conforming
gradation must fall inside. A gradation limit is a curve, not a
number, so it is not an acceptance criterion like the other
requirements of the platform: an acceptance criterion carries an
operator and a limit with min, value and max, which expresses a
scalar band but not a percent-passing curve across a dozen sieve
sizes. The pair has the shape that diggs:GroutSpecificationType uses
for the aggregate in a grout mix, with the generic
diggs:SieveAnalysisPropertyType rather than a grout-specific type.
It is provisional pending confirmation by the subject matter expert;
see diggs:RILTPSpecification.
