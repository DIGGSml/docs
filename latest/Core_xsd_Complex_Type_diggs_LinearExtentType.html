The type of local or permanent reference datum for vertical
gravity-based (elevation and vertical depth) and measured depth
coordinates, in the context of a borehole or well. It follows
eml:WellboreDatumReference and is associated with the origin (first
point) of the linear extent. Values come
from the enumerated list, or "Other: xx", where xx is a user-defined
term whose meaning differs from every listed value (not a synonym of
one).

Element diggs:LinearExtentType / diggs:anchorPoint
Namespace http://diggsml.org/schemas/3
Annotations
 
A calibration point that relates measure values to geometric
positions along this linear extent. It is needed only when the
length of the linear element does not correspond to the length
computed from the coordinates: when physical core length differs
from measured depth (anchors at top and bottom enable scaling, as
for expanded or compressed core), when downhole surveys or GPS
waypoints provide control points for adjusting the geometry, or when
measures cannot be computed directly from the centerline geometry.
Where measures are computed by interpolating along the geometry,
anchor points are not needed. Repeat for each point.
