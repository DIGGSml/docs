Element diggs:NonConformanceType / diggs:disposition
Namespace http://diggsml.org/schemas/3
Annotations
 
What was decided about the non-conforming work: accept as is,
repair, rework, replace or reject. Required: the decision is what
this record exists to hold. Distinct from correctiveAction: the
disposition concerns this non-conforming work, whereas a corrective
action concerns the cause, so that the next item does not fail the
same way. Use the DIGGS dictionary disposition.xml for the list of
values.

Element diggs:NonConformanceType / diggs:breachedSpecificationRef
Namespace http://diggsml.org/schemas/3
Annotations
 
The requirement that was not met, typically a
diggs:DesignConformanceCriterion, a diggs:PerformanceCriterion or a
diggs:CompositeAcceptanceCriterion. Repeat where one departure
breaches several requirements. Optional where the requirement is
stated only in a specification document (an attachment, described in
remark), or is the criterion of the check cited by detectedByRef.
Given by reference only.
