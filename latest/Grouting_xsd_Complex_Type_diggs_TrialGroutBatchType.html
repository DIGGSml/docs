Annotations
 
Elapsed time between the batch's delivery (arrival at
the point of use, e.g. off a ready-mix truck) and its placement
(Installation Parameter Analysis row 32, S23). Real, unrecorded data
until now: neither this type nor diggs:AbstractSampleType, its
ultimate base, carried any time field at all - only reference
elements (samplingActivityRef, programRef and siblings). The
transport window governs whether the batch is still placeable by the
time it reaches the hole, so it belongs on the type this project's
own trial/production split shares (diggs:TrialGroutBatchType is the
base both diggs:TrialGroutBatch and, through it,
diggs:GroutBatchType extend), rather than duplicated on
diggs:GroutBatchType alone - a trial batch has the same transport
question between mixing and test placement that a production batch
has between mixing and column placement.
