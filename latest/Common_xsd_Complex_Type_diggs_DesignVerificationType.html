global stability, the Column-Wall Method (CWM), Equivalent Strength
Method (ESM), Stress Reduction Method (SRM), Pile Support Method
(PSM) or numerical analysis with the actual RI layout. Use the DIGGS

Namespace http://diggsml.org/schemas/3
Annotations
 
The load case this verification was run against, as the set of
diggs:DesignLoad objects that combine to define it, for example the
permanent and seismic loads active in a seismic buckling check, as
distinct from the permanent and variable loads active in a static
one. Repeat for each load in the case. Given by reference only.
