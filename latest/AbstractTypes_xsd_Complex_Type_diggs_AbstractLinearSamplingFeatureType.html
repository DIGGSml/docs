Element diggs:AbstractLinearSamplingFeatureType / diggs:centerLine
Namespace http://diggsml.org/schemas/3
Annotations
 
The linear geometry of the feature, as a diggs:LinearExtent,
defining its shape and location. For a borehole the line is the
trajectory of the borehole in 3D space. Several center lines, all
associated with the same reference point, may define complex objects
such as a wellbore with sidetracks, or different reference datums
for one borehole.

Element diggs:AbstractLinearSamplingFeatureType / diggs:alignmentDeviation
Namespace http://diggsml.org/schemas/3
Annotations
 
How far the constructed feature departed from its intended
alignment, as a dimensionless ratio: the horizontal offset
accumulated over the length travelled. Use uom="Euc" for a ratio
(0.02) or uom="%" for a percentage (2); a 1:50 tolerance is 0.02 Euc
or 2 %. It measures deviation from the intended alignment, not from
vertical. Where no intended plunge is stated anywhere, vertical is
the intent, as it is for rigid inclusion columns. For a feature
intended to be raked, such as a grout hole or a battered pile, it
carries only the construction error and not the design rake: a pile
intended at 1:4 and built almost perfectly reports a small
deviation, not 25 %. The datum is intendedPlunge where given,
otherwise the plunge stated by the design or target object for this
feature, otherwise vertical. Which source governs: where the center
line is genuinely inclined it is a survey and governs, and this
property is a derived convenience that should agree with it. Where
the center line is vertical it is almost certainly nominal rather
than measured, and this property carries the measurement; many
construction techniques yield only an inclination (for example of
the rig mast) with no azimuth, so no center line can be surveyed.
Read alignmentDeterminationMethod rather than inferring from the
geometry, since coordinate rounding can make a nominal center line
slightly non-vertical.

Element diggs:AbstractLinearSamplingFeatureType / diggs:intendedPlunge
Namespace http://diggsml.org/schemas/3
Annotations
 
The plunge the feature was intended to be constructed at, against
which alignmentDeviation is measured, in the same angular convention
as plunge. Populate it only where the intent is not otherwise
recoverable, that is, where the design or target object carrying the
planned rake is not transferred with the file; where it is, that
object is the authority and this element should be omitted. Omit it
for a feature intended to be vertical, such as a rigid inclusion
column.

Element diggs:AbstractLinearSamplingFeatureType / diggs:alignmentDeterminationMethod
Namespace http://diggsml.org/schemas/3
Annotations
 
How the alignment was established: a downhole inclinometer or
pendulum in the open hole, an ultrasonic caliper, the inclination of
the rig mast, or not determined. This is the provenance of the
trajectory and the only place it can be stated: a center line is
mandatory, so a feature whose trajectory was never surveyed must
still assert one, and a nominal vertical line is otherwise
indistinguishable from a surveyed one. A mast-derived value
describes the rig, not the finished element, which is a weaker claim
than a downhole survey. Absent, together with an exactly vertical
center line and no alignmentDeviation, the alignment was not
determined; read this as an absence of information, not a claim of
verticality. Use the DIGGS dictionary
alignmentDeterminationMethod.xml for the list of values.
