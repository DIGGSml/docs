Element diggs:AbstractPileType / diggs:referenceElevation
Namespace http://diggsml.org/schemas/3
Annotations
 
A true vertical control position, in the same vertical CRS as the
referencePoint, that is used to set elevations for the structural elements, and not
the top of the piling. This property is used when groundSurfaceElevation is not used
as the reference elevation.
                                
An elevation is a position, not a length. The value may be given as a
one-dimensional position in a vertical CRS, as a one-dimensional position in this
pile's own linear referencing system, or as a full three-dimensional position;
srsName on the PointLocation states which, and overrides the referencePoint default
above. Populate uomLabels so that a consumer can read the unit without resolving the
CRS.
