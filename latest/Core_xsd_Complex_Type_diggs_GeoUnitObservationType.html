Namespace http://diggsml.org/schemas/3
Annotations
 
The vertical distance from the feature's reference point to the top
(or beginning) of the unit. It applies only to a one-dimensional
unit observed along a single linear sampling feature, such as a
borehole log; for a unit synthesized across many boreholes, hold a
three-dimensional geometry in diggs:location instead.
