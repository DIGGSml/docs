Element diggs:basedOnRef
Namespace http://diggsml.org/schemas/3
Annotations
 
A reference to a more general program module that this one specializes. Resolution
is per property, most specific first: a value stated on the referring object
overrides the same property stated on the target. The target must belong to the same
substitution-group head as the referring object (a design cites a design, a
specification a specification, a basis a basis), and chains must be acyclic; the
validation chain checks both. A design that cites a specification belongs in
programSpecificationRef instead. Distinct from basisRef, which cites the evidence a
design was prepared from rather than a more general object of the same kind.
